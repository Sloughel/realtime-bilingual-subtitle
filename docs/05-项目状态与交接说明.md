## 3. 已踩过的坑与既定解法（M1 会再次遇到，务必先读）

1. **CUDA DLL 注册（最关键）**：pip 安装的 `nvidia-*-cu12` 包不会自动登记 DLL 目录，
   Windows 上必须在**导入 ctranslate2 / faster-whisper 之前**执行
   `os.add_dll_directory()` 并追加 `PATH`。目录为
   `.venv/Lib/site-packages/nvidia/{cublas,cudnn,cuda_nvrtc}/bin`，
   **且必须传入绝对路径**（相对路径会报 `WinError 87`）。
   → 服务端启动代码必须内置这段逻辑，参考 `scripts/check_env.py` 的 `add_nvidia_dll_dirs()`。

2. **Git Bash 里中文 grep 不可靠**：曾因 `grep 中文` 匹配失败而误判"用户未保存文件"。
   → 一切文本核查改用 Python（`Path.read_text(encoding='utf-8')` + 字符串包含判断）。

3. **下载器选择**：同一镜像下 Python `urllib` 仅约 0.5MB/s，`curl` 可达 4~6MB/s（约 8 倍）。
   → 大文件下载一律用 curl 作传输引擎。

4. **sdkmanager 下载平台包曾损坏**（`Error on ZipFile unknown archive`）：
   → 改为直接 `curl` 从 `dl.google.com` 取 zip 手动解压。

5. **DeepSeek 密钥不可出现在对话中**：对话会进入 AI 协作记录，而该记录要提交。
   → 密钥只写 `server/.env`，脚本只报告"已配置/长度"，不打印内容。

## 6. M1 任务清单与实现要点

任务与验收标准详见 04 文档 §2「M1 服务端」表（1.1~1.6）。实现契约是 **03 文档**，要点：

| 任务 | 实现要点 |
|---|---|
| 1.1 工程骨架与配置加载 | `server/app/settings.py` 读 `server/.env`；**启动即注册 NVIDIA DLL**（见 §3 第 1 条） |
| 1.2 WebSocket 协议 | 端点 `/ws`；二进制音频帧为 **6 字节头（magic 0xAF + version + uint32 大端 seq）+ 3200 字节 PCM16**；控制消息与错误码见 03 §2/§4/§5/§6 |
| 1.3 VAD 断句器 | **不要用 `get_speech_timestamps()`（离线）**，改用 `get_vad_model()` 取 `SileroVADModel`（含状态），按 **512 采样点/块** 取语音概率并自行累计静音；参数映射见 03 §9.3 |
| 1.4 faster-whisper 接入 | 模型路径取自 `.env` 的 `WHISPER_MODEL`（相对项目根目录）；`language` 按会话 `src_lang` 固定；串行队列独占 GPU |
| 1.5 DeepSeek 翻译接入 | **密钥已就绪，可真实跑通**；实现 Translator 抽象 + 重试（2 次，1s/2s 退避）+ 降级回传原文 + 超时 10s；prompt 见 03 §10 |
| 1.6 端到端集成测试 | 用 `server/tests/fixtures/sample_en.wav` 经模拟客户端灌入，校验 subtitle JSON 与各阶段耗时；产出延迟统计 |
| 另需实现 | **FR-21 成本监控与通知**（逐句累计 token 并按模型定价折算，达阈值通知并重置计数）、§5 故障模式 FM-01~09 的降级策略 |

**M1 不需要用户手机**，全部可本机自测。

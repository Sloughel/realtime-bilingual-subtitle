## 3. 已踩过的坑与既定解法（M1 会再次遇到，务必先读）

1. **CUDA DLL 注册（最关键）**：pip 安装的 `nvidia-*-cu12` 包不会自动登记 DLL 目录，
   Windows 上必须在**导入 ctranslate2 / faster-whisper 之前**执行
   `os.add_dll_directory()` 并追加 `PATH`。目录为
   `.venv/Lib/site-packages/nvidia/{cublas,cudnn,cuda_nvrtc}/bin`，
   **且必须传入绝对路径**（相对路径会报 `WinError 87`）。
   → 服务端启动代码必须内置这段逻辑，参考 `scripts/check_env.py` 的 `add_nvidia_dll_dirs()`。

2. **Git Bash 里中文 grep 不可靠**：曾因 `grep 中文` 匹配失败而误判"用户未保存文件"。
   → 一切文本核查改用 Python（`Path.read_text(encoding='utf-8')` + 字符串包含判断）。

3. **下载器选择**：同一镜像下 Python `urllib` 仅约 0.5MB/s，`curl` 可达 4~6MB/s（约 8 倍）。
   → 大文件下载一律用 curl 作传输引擎。

4. **sdkmanager 下载平台包曾损坏**（`Error on ZipFile unknown archive`）：
   → 改为直接 `curl` 从 `dl.google.com` 取 zip 手动解压。

5. **DeepSeek 密钥不可出现在对话中**：对话会进入 AI 协作记录，而该记录要提交。
   → 密钥只写 `server/.env`，脚本只报告"已配置/长度"，不打印内容。

6. **VAD 模型并非跨调用有状态**（M1 实测发现）：`faster_whisper.vad.SileroVADModel.__call__`
   每次都把 LSTM 状态 `h`/`c` 重置为零。直接按 512 采样点分块调用会丢失时间上下文。
   → 服务端自行持有 ONNX 会话与 `h`/`c`/64 采样点上下文，见 `app/segmenter.py` 的
   `StreamingVADModel`；03 文档 §9.3 已据此更正。

7. **冷启动会污染延迟统计**（M1 实测发现）：首次 ASR 推理约 1700ms（CUDA kernel 初始化）、
   首次翻译请求约 4871ms（TLS 建连），会把首句字幕延迟严重拉高。
   → 模型加载后**预热一次推理**（`app/asr.py`），服务启动时**预热翻译端点**（一次 GET，
   不耗 token，`app/translate.py`）。

8. **FastAPI WebSocket 处理函数的参数必须加类型注解**：`@app.websocket` 的处理函数中，
   未注解的 `websocket` 参数会被当作**查询参数**校验，导致连接以 1008 被拒。
   → 注解为 `WebSocket`（见 `app/main.py`）。

9. **端到端延迟必须按帧到达时刻计算**：用「首帧时间 + 标称音频位置」估算会被客户端发送
   漂移污染（实测偏差近 2 倍）。→ 记录每帧到达时刻并按音频位置查表（`app/session.py`）。

10. **Gradle 官方分发在本机不可达**（services.gradle.org 307 到 GitHub，连接被重置）：
    → 用华为云镜像 `https://mirrors.huaweicloud.com/gradle/gradle-8.7-bin.zip`；
    Maven 依赖统一走阿里云镜像（已在 `android/settings.gradle.kts` 配置）。
11. **AAPT2 不认无版本限定的 adaptive-icon 目录**：把 `mipmap-anydpi-v26` 改成 `mipmap-anydpi`
    会导致 `resource mipmap/ic_launcher not found`（minSdk 29 也一样）。
    → 保留 `mipmap-anydpi-v26`；lint 的 `ObsoleteSdkInt` 只是警告。
12. **lint 的 `MissingPermission` 会阻断构建**：`@SuppressLint("MissingPermission")` 必须加在
    **真正构造 `AudioRecord` 的函数**上（只加在 `start()` 上不够，`openRecord()` 仍会报错）。

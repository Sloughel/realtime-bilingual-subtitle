| 项目名称 | 实时双语字幕系统 |

## 1. 协议总则

| 项 | 规定 |
|---|---|
| 传输 | WebSocket（RFC 6455），服务端端点 `/ws` |
| 协议版本 | 1（字段 `protocol_version`） |
| 编码 | 控制消息为 JSON（UTF-8）文本帧；音频为二进制帧；一个 WebSocket 帧只承载一条消息 |
| 字节序 | 网络字节序（大端） |
| 默认端口 | 8000 |

## 2. 连接与握手

**客户端请求**：

```
GET ws://<host>:8000/ws?protocol_version=1&session_id=<uuid4>
```

- `session_id`：客户端生成的 UUID，用于断线重连恢复。
- 协议版本不支持时，服务端回 `error`（1002）并关闭连接。

**服务端应答**（hello）：

```json
{
  "type": "hello",
  "protocol_version": 1,
  "server_version": "0.1.0",
  "server_time": 1757318400000,
  "limits": {
    "max_sentence_ms": 15000,
    "chunk_ms": 100,
    "sample_rate": 16000
  }
}
```

连接建立后，客户端必须发送 `config` 并收到 `config_ack`，服务端才开始接受音频帧。

## 3. 音频帧格式（客户端 → 服务端，二进制）

| 字段 | 偏移 | 长度 | 说明 |
|---|---|---|---|
| magic | 0 | 1 | 固定 0xAF |
| version | 1 | 1 | 固定 1 |
| seq | 2 | 4 | uint32 大端，从 1 起递增 |
| payload | 6 | 3200 | 100ms × 16000Hz × 2 字节，PCM16 小端、单声道 |

- 帧总长 **3206 字节**。payload = 1600 采样点 = 100ms。
- 末尾不足 3200 字节的块以静音（0x00）填充，误差由 VAD 静音容错吸收。
- `seq` 用于丢帧检测：服务端容忍少量丢帧（仅记录统计），不影响整句处理。
- 非法帧（magic 错误 / 长度不符）被忽略并计数，连续 10 帧非法回 `error`（2001）。

## 4. 控制消息（客户端 → 服务端）

### 4.1 config —— 会话配置

```json
{
  "type": "config",
  "mode": "mic",
  "src_lang": "en",
  "tgt_lang": "zh",
  "sample_rate": 16000,
  "chunk_ms": 100
}
```

| 字段 | 取值 |
|---|---|
| mode | `"mic"`（麦克风）/ `"media"`（媒体声音） |
| src_lang / tgt_lang | 语言枚举（§8），v1.0 支持 en→zh |
| sample_rate / chunk_ms | 固定 16000 / 100 |

### 4.2 其他控制消息

| 消息 | 说明 |
|---|---|
| `{"type":"start"}` | 开始处理（显式开启采集/处理） |
| `{"type":"stop"}` | 停止：冲刷当前句（立即断句并处理剩余音频） |
| `{"type":"reset"}` | 丢弃当前未断句的音频 |
| `{"type":"ping","t":1757318400000}` | 心跳，服务端回 pong |

## 5. 服务端消息（服务端 → 客户端）

### 5.1 config_ack

```json
{
  "type": "config_ack",
  "ok": true,
  "session_id": "3f2a...",
  "applied": {"src_lang": "en", "tgt_lang": "zh"},
  "warnings": []
}
```

### 5.2 subtitle —— 核心消息（双语字幕）

```json
{
  "type": "subtitle",
  "sentence_id": 17,
  "seq_start": 100,
  "seq_end": 152,
  "source": "This is a demo sentence.",
  "translation": "这是一句演示。",
  "src_lang": "en",
  "tgt_lang": "zh",
  "start_ms": 10100,
  "end_ms": 15200,
  "created_ms": 1757318403400,
  "asr_ms": 320,
  "translate_ms": 1100
}
```

| 字段 | 说明 |
|---|---|
| sentence_id | 会话内单调递增；客户端按 id 去重（重连后幂等） |
| seq_start / seq_end | 该句对应的音频帧序号区间 |
| start_ms / end_ms | 该句在音频流中的时间范围（会话开始起算） |
| asr_ms / translate_ms | 各阶段耗时（延迟验收数据来源） |
| translation | 翻译失败降级时等于 source，并伴随 error 消息 |

### 5.3 其他消息

| 消息 | 说明 |
|---|---|
| `{"type":"partial","sentence_id":17,"text":"..."}` | **v1.1 预留**：识别中间结果 |
| `{"type":"status","code":"recognizing","message":"..."}` | 状态通知（可选） |
| `{"type":"error","code":3001,"message":"ASR failed","recoverable":true}` | 错误通知 |
| `{"type":"pong","t":1757318400000}` | 心跳应答 |

## 6. 错误码与降级策略

| 码 | 含义 | 服务端行为 |
|---|---|---|
| 1001 | 参数非法 | 回 error 并忽略该消息 |
| 1002 | 协议版本不支持 | 回 error 并关闭连接 |
| 2001 | 音频帧格式错误（连续 10 帧） | 回 error，继续服务 |
| 3001 | ASR 失败 | 丢弃该句，回 error（recoverable） |
| 4001 | 翻译失败（API 错误） | 降级回传原文并标记，回 error |
| 4002 | 翻译超时（10s） | 同上 |
| 5001 | 服务器繁忙（队列积压超过上限） | 丢弃最旧句，回 error |

**原则：单句错误永不导致连接断开。**

## 7. 断线重连

- 客户端指数退避重连：1s → 2s → 4s → 8s → 10s（封顶），无限重试；UI 显示"重连中"。
- 重连时携带同一 `session_id`；服务端会话保留 30s（可配）。
- 重连后客户端重发 `config`；断线期间未完成的半句作废。
- 已回传的 subtitle 不重放；客户端按 `sentence_id` 幂等去重。

## 8. 语言枚举与方向矩阵

**枚举**：`zh`（中文）、`en`（英语）、`ja`（日语）、`auto`（预留，v1 不实现）。

| 版本 | 支持方向 | 状态 |
|---|---|---|
| v1.0 | en → zh | 基础版 |
| 扩展 | zh → en | 协议已支持，待实现 prompt 与测试 |
| 远期 | 新增语言对（以 ja ↔ zh 作扩展演示） | 协议按 src/tgt 语言对抽象，新增语言对只需扩充上表枚举与语言名映射（S1 语言扩展），管道与消息格式不变 |

语言名称映射（用于 prompt）：en=英语、zh=中文、ja=日语。**新增语言对时在此登记名称映射，并在 §10 的 prompt 模板中代入即可，无需改动协议。**

## 9. 服务端内部接口

### 9.1 ASR 抽象

```python
class ASREngine(Protocol):
    def transcribe(self, pcm_16k_mono: bytes) -> str: ...
```

faster-whisper 实现要点：

| 项 | 值 |
|---|---|
| 模型 | medium（默认，可配 small / large-v3） |
| 设备 / 精度 | cuda / float16（CPU 环境降级 int8） |
| language | 按会话 src_lang 固定（v1.0 为 en） |
| beam_size | 1（VAD 已由上游完成，关闭 vad_filter） |
| 并发 | 串行队列（GPU 独占） |

### 9.2 翻译抽象

```python
class Translator(Protocol):
    async def translate(self, text: str, src_lang: str, tgt_lang: str) -> str: ...
```

DeepSeek 实现要点（OpenAI 兼容）：

| 项 | 值 |
|---|---|
| 端点 | `POST {base_url}/chat/completions`（默认 https://api.deepseek.com） |
| model | deepseek-chat |
| temperature | 0.3 |
| max_tokens | max(64, 2×len(text)+20) |
| 超时 | 10s |
| 重试 | 2 次，指数退避 1s / 2s |
| 并发上限 | 3 |

### 9.3 VAD 与断句参数

| 参数 | 值 |
|---|---|
| 模型 | silero-vad v5 |
| threshold | 0.5 |
| min_speech_ms | 300（最短有效语音） |
| min_silence_ms | 500（静音达到即切句） |
| max_sentence_ms | 15000（句长硬上限） |
| pre_roll_ms | 200（句首回溯，避免吞掉首音） |

### 9.4 服务端配置项

| 配置项 | 默认值 | 说明 |
|---|---|---|
| SERVER_HOST / SERVER_PORT | 0.0.0.0 / 8000 | 监听地址 |
| WHISPER_MODEL | medium | small / medium / large-v3 |
| WHISPER_DEVICE / COMPUTE_TYPE | cuda / float16 | CPU 环境 int8 |
| VAD_MIN_SILENCE_MS | 500 | 断句静音阈值 |
| TRANSLATE_BASE_URL | https://api.deepseek.com | OpenAI 兼容端点 |
| TRANSLATE_API_KEY | （必填） | 仅存服务端环境 |
| TRANSLATE_MODEL | deepseek-chat | 模型名 |
| SESSION_TTL_S | 30 | 会话保留时长 |
| MAX_QUEUE | 10 | ASR+翻译积压上限 |

## 10. 翻译 Prompt 模板

**system**（src/tgt 名称由 §8 映射代入）：

```
你是一名专业字幕翻译。将用户给出的{src_name}音频转写文本翻译成{tgt_name}。
要求：
1. 只输出译文，不要任何解释、前缀或引用原文；
2. 人名、地名、品牌等专有名词保留原文或使用通用译法；
3. 译文口语化、简短，符合字幕习惯；
4. 不要逐字硬译语气词（如嗯、啊）。
```

**user**：待翻译的转写文本。

## 11. 端到端延迟预算

| 环节 | 预算 | 说明 |
|---|---|---|
| 采集缓冲 | 100ms | 音频分块大小 |
| 局域网传输 | <20ms | 可忽略 |
| 断句静音等待 | ≤500ms | VAD min_silence_ms |
| ASR | ≤800ms/句 | medium @ RTX 4060 |
| 翻译 | ≤1500ms/句 | DeepSeek 正常负载 |
| 渲染 | <50ms | 悬浮窗更新 |
| **合计** | **≤3s（P95）** | 句末 → 字幕上屏 |

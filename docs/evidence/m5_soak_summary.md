# NFR-04 30 分钟满载采样汇总

| 项目 | 内容 |
|---|---|
| 目的 | 验证服务端在持续音频负载下 30 分钟无崩溃、无内存持续增长 |
| 日期 | 2026-10-19 20:33:26–21:03:24 |
| 实例 | 独立服务端 `127.0.0.1:8010`（与 M3 的 8000 实例隔离，避免污染其统计） |
| 负载 | `scripts/mock_client.py --realtime` 循环回放 17.28s 英文音频，每轮 5 句 |
| 采样 | `scripts/monitor_server.py --port 8010 --interval-s 10`，179 个样本 |
| 硬件 | RTX 4060 8GB / Windows 11 / Python 3.10.6 |
| 原始数据 | [`m5_soak_monitor.csv`](m5_soak_monitor.csv)、[`m5_soak_status.json`](m5_soak_status.json) |

## 1. 结果

| 指标 | 结果 |
|---|---|
| 实际时长 | **29.97 分钟**（179 个 10s 样本） |
| 回放轮次 | **66 轮**，每轮 5 句，全部成功 |
| 字幕句数 | **330 句** |
| 端到端延迟 | 平均 1882.4ms，P50 1896.5ms，**P95 2201.8ms**，最大 2514ms |
| ASR P95 | 787.7ms |
| 翻译 P95 | 1002.6ms |
| 错误/降级/重试 | 0 / 0 / 0 |
| 空识别 / 丢帧 / 非法帧 | 0 / 0 / 0 |
| 崩溃 / 进程退出 | 无（PID 34356 全程存活） |
| 服务端 RSS | **217.1–685.9MB**；起始 654.0MB，结束 217.2MB，**无持续增长** |
| GPU 显存（整卡） | **4423–5039MB**；起始 4481MB，结束 4657MB，有升有降 |
| 翻译成本 | 330 次调用，32604 输入 / 2244 输出 tokens，约 **0.083 元** |

## 2. 判读

- **稳定性通过**：30 分钟、66 轮、330 句持续负载下进程未退出，错误/降级/重试均为 0。
- **无内存泄漏迹象**：RSS 从 654MB 降至 217MB（会话回收后释放），没有单调上升；峰值 686MB
  出现在前 20 分钟，之后回落。
- **GPU 未失控**：整卡显存 4.4–5.0GB 波动，峰值后回落；本次为**两个服务实例**
  （8000 的 M3 实例 + 8010 的测试实例）加桌面占用，不能直接等同于单实例的 2.57GB。
  单实例显存数据见 M3 实测（加载后 2566MB）。
- **延迟顺带得到验证**：330 句 P95 2201.8ms，低于 M3 的 2475ms，说明 8s 切句与连接保活
  在长时间运行下没有退化。

## 3. 口径与局限

1. 负载是**同一段 17.28s 音频的循环回放**，不是 30 分钟真人使用；它覆盖不了说话人切换、
   长句、噪声等真实变化，但能覆盖内存泄漏、显存增长、连接泄漏与长时间运行崩溃。
2. 每轮之间客户端会断开并新建会话，因此也间接验证了会话回收与跨会话统计；但没有验证
   30 分钟内单连接持续不断开的极端情况（M3 已有 11 分钟真机连续使用）。
3. GPU 显存由 `nvidia-smi` 整卡采样，Windows 下无法可靠拆分到单进程；本次结论只声明
   「整卡未超过 6GB 且无单调增长」，不声明单实例精确值。
4. 延迟统计来自服务端 `/status`，与客户端每轮的 `平均/最大` 输出一致
   （客户端 66 轮均值 1882.6ms，与服务器 1882.4ms 对齐）。

## 4. 复现

```bash
# 终端 A：独立实例（避免污染 8000 的 M3 数据）
cd server
SERVER_PORT=8010 SERVER_HOST=127.0.0.1 ../.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8010

# 终端 B：资源采样
.venv/Scripts/python.exe scripts/monitor_server.py --port 8010 --duration-min 30 --out logs/m5_soak_monitor.csv

# 终端 C：30 分钟实时回放（每轮约 27s）
i=0; while [ $SECONDS -lt 1800 ]; do i=$((i+1)); \
  .venv/Scripts/python.exe scripts/mock_client.py --port 8010 --wav server/tests/fixtures/sample_en.wav --realtime; \
done

# 结束后取汇总
curl -s http://127.0.0.1:8010/status
```

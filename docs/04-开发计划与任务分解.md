## 1. 里程碑总览

| 里程碑 | 目标 | 预计工期 | 产出/验收 |
|---|---|---|---|
| M0 | 环境准备 | 0.5 天 | JDK 17、Android Studio/SDK/adb、Python 虚拟环境、DeepSeek key、手机调试就绪 |
| M1 | 服务端全链路 | 2 天 | 协议+断句+ASR+翻译，离线音频端到端输出字幕 JSON（无需手机） |
| M2 | Android 客户端 | 2~3 天 | 双采集模式 + 网络层 + 悬浮窗 + 控制页 |
| M3 | 端到端联调 | 1 天 | 真机两种模式验收、延迟达标、30 分钟稳定性 |
| M4 | 扩展实施（可选） | 每个 1~2 天 | E1 互联网 → E2 本地 LLM → E3 Linux → E4 iOS/鸿蒙，按优先级 |
| M5 | 报告与演示 | 2 天 | 课程报告定稿、演示视频、README、仓库整理 |

基础版（M0~M3 + M5）预计 **8~10 天**；含全部扩展 12~18 天。按课程截止时间倒排，建议预留 20% 缓冲。

## 2. 任务分解

### M0 环境准备（用户 + agent 协作）— 已完成

机器基线：Python 3.10.6 ✓、RTX 4060 8GB（驱动 551.78 / CUDA 12.4）✓、Git ✓、winget ✓；
初始缺失：Java 仅 JRE 1.8、无 Android SDK 与 adb。

采用**命令行工具链**方案（未安装 Android Studio，便于 agent 自动化构建），组件全部装于用户目录，无需管理员权限：

| 组件 | 版本 | 路径 |
|---|---|---|
| JDK（Temurin） | 17.0.20.1 | `C:\Users\38915\dev\jdk17\jdk-17.0.20.1+1` |
| Android SDK | platform-tools 37.0.1 / API 34 / build-tools 34.0.0 | `C:\Users\38915\dev\android-sdk` |
| Python 环境 | 3.10.6 + venv | `bilingual-subtitle/.venv` |
| whisper 模型 | medium，置于项目内以支持离线演示 | `bilingual-subtitle/models/faster-whisper-medium` |

已写入用户环境变量 `JAVA_HOME`、`ANDROID_HOME`、`ANDROID_SDK_ROOT`，并将 `jdk17\bin`、
`platform-tools`、`cmdline-tools\latest\bin` 加入 `PATH`（对已打开的终端需重开才生效）。

**验收结果**

- `scripts/check_env.py` 环境自检通过（依赖版本、CUDA DLL 注册、配置有效性）
- `scripts/verify_asr.py` ASR 链路通过：17.28s 英文测试音频 → 识别 1.95s（**8.9 倍实时率**），
  平均 390ms/段，满足 NFR-01 的 800ms 预算；语言识别 en（置信度 1.00）
- CTranslate2 识别到 1 个 CUDA 设备，支持 float16

**网络环境注意**：huggingface.co 与 github.com 需经本地代理（`127.0.0.1:10810`）；
模型权重走 `hf-mirror.com`、pip 走清华镜像。`scripts/download_model.py` 以 curl 作传输引擎
（同一镜像下 Python urllib 仅约 0.5MB/s，curl 可达 4~6MB/s）。

### M3 端到端联调

- 真机测试：麦克风模式、媒体声音模式（目标 App 建议 YouTube）各 ≥10 分钟。
- 延迟核对：各环节耗时统计 ≤3s（NFR-01）。
- 异常演练：断网重连、服务端重启、防火墙拦截。
- Bug 修复循环：用户通过 `adb logcat` 回传日志 → agent 定位修复。

## 4. 测试策略

| 层级 | 内容 | 工具/方式 |
|---|---|---|
| 单元测试 | 协议编解码、断句器（标注 wav）、翻译 prompt（快照测试） | pytest |
| 集成测试 | 离线音频文件 → 服务端 → 校验字幕 JSON（全程无手机参与） | scripts/ 模拟客户端 |
| 系统测试 | 真机双模式、语言方向、断连重连、30min 稳定性 | 真机 + adb logcat |
| 性能测试 | telemetry 各环节耗时 → 延迟报告 | 服务端日志统计 |
| 测试语料 | TED 片段（英）、中文新闻（zh→en 扩展用）、日剧片段（S1 语言扩展演示用） | 本地 wav 文件 |

## 5. 风险清单

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| 媒体声音被目标 App 禁止捕获 | 中 | 高 | 麦克风模式兜底；演示选用允许捕获的 App（如 YouTube）；文档说明限制 |
| 手机厂商系统限制悬浮窗 | 中 | 中 | 授权引导页；备选机型测试 |
| 手机 Android <10 | 中 | 高 | 提前确认设备；媒体模式不可用则演示麦克风模式 |
| DeepSeek 限流/欠费 | 低 | 中 | 重试+降级回传原文；备用 key |
| whisper 速度/显存不达预期 | 低 | 中 | 降级 small / int8 |
| Windows 防火墙拦截局域网 | 高 | 低 | 文档给出放行步骤；M3 联调前做连通性检查 |
| 演示时网络不稳 | 中 | 高 | 手机热点直连主机备选 |
| Java 8 环境 | 已确认 | 低 | M0 安装 JDK 17 |
| 翻译质量波动（口语/专名） | 中 | 低 | prompt 迭代 + 抽检语料库 |

## 6. 交付物清单

- **GitHub 仓库**：server/、android/、scripts/、docs/ 四份设计文档、README（快速开始 + 演示步骤 + 企业自托管部署说明）、LICENSE（开源协议）、.gitignore（排除 .env 与密钥）。
- **课程报告**：按"需求（01 文档）→ 设计（02/03 文档）→ 实现 → 测试 → 总结与展望（含企业隐私部署愿景）"组织，本系列文档即报告素材。
- **演示视频脚本建议（3~5 分钟）**：
  1. 连接配置：输入主机 IP → 连接成功；
  2. 媒体声音模式：手机播放英文视频 → 悬浮窗实时中文字幕；
  3. 麦克风模式：现场对话 → 双语字幕；
  4. 悬浮窗操作：拖动、调透明度；
  5. 语言方向切换演示（扩展后）。
- **演示失败预案**：预录屏 + 离线音频回放模式（模拟客户端）。

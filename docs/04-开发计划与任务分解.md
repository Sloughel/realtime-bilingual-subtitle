## 1. 里程碑总览

| 里程碑 | 目标 | 预计工期 | 产出/验收 |
|---|---|---|---|
| M0 | 环境准备 | 0.5 天 | JDK 17、Android Studio/SDK/adb、Python 虚拟环境、DeepSeek key、手机调试就绪 |
| M1 | 服务端全链路 | 2 天 | 协议+断句+ASR+翻译，离线音频端到端输出字幕 JSON（无需手机） |
| M2 | Android 客户端 | 2~3 天 | 双采集模式 + 网络层 + 悬浮窗 + 控制页 |
| M3 | 端到端联调 | 1 天 | 真机两种模式验收、延迟达标、30 分钟稳定性 |
| M4 | 扩展实施（可选） | 每个 1~2 天 | E1 互联网 → E2 本地 LLM → E3 Linux → E4 iOS/鸿蒙，按优先级 |
| M5 | 报告与演示 | 2 天 | 课程报告定稿、演示视频、README、仓库整理 |

基础版（M0~M3 + M5）预计 **8~10 天**；含全部扩展 12~18 天。按课程截止时间倒排，建议预留 20% 缓冲。

## 2. 任务分解

### M0 环境准备（用户 + agent 协作）

当前机器检查结果：Python 3.10 ✓、RTX 4060（CUDA 12.4）✓、Git ✓；**Java 为 1.8（需升级 JDK 17）、adb 缺失（需装 Android SDK 平台工具）**。

| 任务 | 说明 |
|---|---|
| 安装 JDK 17 | Temurin 17 或 Android Studio 内置 JBR；当前 Java 8 不满足 Android 新版构建要求 |
| 安装 Android Studio | 含 SDK 34、platform-tools（adb） |
| 手机调试就绪 | 开发者模式、USB 调试；确认 Android 版本 ≥10（媒体声音模式硬性要求） |
| Python 虚拟环境 | venv + requirements（FastAPI、faster-whisper、onnxruntime、httpx 等） |
| DeepSeek API key | 申请并写入服务端 .env（不入库） |

### M1 服务端（agent 完成，本机可自测）

| 任务 | 验收标准 |
|---|---|
| 1.1 工程骨架与配置加载 | 服务可启动，配置校验生效 |
| 1.2 WebSocket 协议实现（握手/消息/错误码/重连） | 协议单元测试通过 |
| 1.3 VAD 断句器 | 离线 wav 切句边界与标注误差 ≤±300ms |
| 1.4 faster-whisper 接入（CUDA） | 英文 wav 转写可读，单句 ≤800ms |
| 1.5 DeepSeek 翻译接入（抽象+重试+降级） | 100 句抽检语义正确率 ≥95% |
| 1.6 端到端集成测试 | 模拟客户端播放离线音频 → 校验字幕 JSON；生成延迟统计 |

### M2 Android 客户端（agent 写码 + 用户真机验证）

| 任务 | 验收标准 |
|---|---|
| 2.1 工程骨架 | minSdk 29、Compose、权限清单正确 |
| 2.2 MicSource（AudioRecord + 重采样） | 采集 16k mono PCM16 正常 |
| 2.3 MediaSource（MediaProjection + AudioPlaybackCapture） | 捕获视频 App 声音正常 |
| 2.4 WsClient（帧封装、重连退避） | 协议帧与 03 文档一致 |
| 2.5 悬浮窗（双语两行、拖动、透明度） | 其他 App 上正常显示 |
| 2.6 控制页（连接配置/模式/语言/开始停止/状态） | 全流程可用 |
| 2.7 权限引导流 | 五项权限引导完整 |
| 2.8 前台服务保活 | 退出 App 采集不中断 |

### M3 端到端联调

- 真机测试：麦克风模式、媒体声音模式（目标 App 建议 YouTube）各 ≥10 分钟。
- 延迟核对：各环节耗时统计 ≤3s（NFR-01）。
- 异常演练：断网重连、服务端重启、防火墙拦截。
- Bug 修复循环：用户通过 `adb logcat` 回传日志 → agent 定位修复。

### M4 扩展实施（基础版验收后按优先级启动）

| 顺序 | 扩展 | 主要工作 |
|---|---|---|
| E1 | 互联网连接 | frp/ngrok 或云服务器 + wss 配置说明；客户端 wss 地址支持 |
| E2 | 本地模型翻译（隐私愿景） | 新增 OllamaTranslator（OpenAI 兼容本地端点），实现全链路数据不出内网 |
| E3 | Linux 主机 | requirements 适配、启动脚本、CUDA 安装指引 |
| E4 | iOS/鸿蒙 | 调研报告 +（可选）麦克风模式原型 |
| S1 | 中日互译 | prompt 模板 + 日语测试语料 |

## 4. 测试策略

| 层级 | 内容 | 工具/方式 |
|---|---|---|
| 单元测试 | 协议编解码、断句器（标注 wav）、翻译 prompt（快照测试） | pytest |
| 集成测试 | 离线音频文件 → 服务端 → 校验字幕 JSON（全程无手机参与） | scripts/ 模拟客户端 |
| 系统测试 | 真机双模式、语言方向、断连重连、30min 稳定性 | 真机 + adb logcat |
| 性能测试 | telemetry 各环节耗时 → 延迟报告 | 服务端日志统计 |
| 测试语料 | TED 片段（英）、中文新闻（zh→en 扩展用）、日剧片段（S1 用） | 本地 wav 文件 |

## 5. 风险清单

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| 媒体声音被目标 App 禁止捕获 | 中 | 高 | 麦克风模式兜底；演示选用允许捕获的 App（如 YouTube）；文档说明限制 |
| 手机厂商系统限制悬浮窗 | 中 | 中 | 授权引导页；备选机型测试 |
| 手机 Android <10 | 中 | 高 | 提前确认设备；媒体模式不可用则演示麦克风模式 |
| DeepSeek 限流/欠费 | 低 | 中 | 重试+降级回传原文；备用 key |
| whisper 速度/显存不达预期 | 低 | 中 | 降级 small / int8 |
| Windows 防火墙拦截局域网 | 高 | 低 | 文档给出放行步骤；M3 联调前做连通性检查 |
| 演示时网络不稳 | 中 | 高 | 手机热点直连主机备选 |
| Java 8 环境 | 已确认 | 低 | M0 安装 JDK 17 |
| 翻译质量波动（口语/专名） | 中 | 低 | prompt 迭代 + 抽检语料库 |

## 6. 交付物清单

- **GitHub 仓库**：server/、android/、scripts/、docs/ 四份设计文档、README（快速开始 + 演示步骤 + 企业自托管部署说明）、LICENSE（开源协议）、.gitignore（排除 .env 与密钥）。
- **课程报告**：按"需求（01 文档）→ 设计（02/03 文档）→ 实现 → 测试 → 总结与展望（含企业隐私部署愿景）"组织，本系列文档即报告素材。
- **演示视频脚本建议（3~5 分钟）**：
  1. 连接配置：输入主机 IP → 连接成功；
  2. 媒体声音模式：手机播放英文视频 → 悬浮窗实时中文字幕；
  3. 麦克风模式：现场对话 → 双语字幕；
  4. 悬浮窗操作：拖动、调透明度；
  5. 语言方向切换演示（扩展后）。
- **演示失败预案**：预录屏 + 离线音频回放模式（模拟客户端）。
